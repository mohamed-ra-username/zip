2. What Is an Activity?
• An Activity is an Android component that provides a screen for user interaction.
• Each Activity usually represents one focused task or screen.
• Examples: LoginActivity, MainActivity, DetailsActivity.
• The Activity loads its interface with setContentView().
• An app can contain several Activities connected through navigation.

Think of an Activity as one screen in your app.

3. What Is an Intent?
• An Intent is a message object describing an action to perform.
• Explicit Intent: names the exact component to open.
• Implicit Intent: describes an action; Android finds a suitable app.
• Intents can carry small pieces of data called extras.
• Common uses: open a screen, share text, dial a number, or view a URL.

7. Pass Data with Intent Extras
Sending data from MainActivity
Intent intent = new Intent(
MainActivity.this, DetailsActivity.class
);
intent.putExtra("USER_NAME", "Sara");
startActivity(intent);

Receiving data in DetailsActivity
String name = getIntent().getStringExtra("USER_NAME");
TextView welcome = findViewById(R.id.textWelcome);
welcome.setText("Welcome, " + name);

The extra key must match exactly on both screens.

9. Open a Web Page with an Implicit Intent

String url = "https://developer.android.com";
Uri webpage = Uri.parse(url);
Intent intent = new Intent(
Intent.ACTION_VIEW, webpage
);
startActivity(intent);

• ACTION_VIEW asks Android to display the supplied data.
• Uri.parse() turns the URL string into a Uri object.
• A browser or another compatible app may handle the request.
Add imports for android.content.Intent and android.net.Uri.

10. Handle Missing or Unexpected Data

String name = getIntent().getStringExtra("USER_NAME");
if (name == null || name.trim().isEmpty()) {
name = "Guest";
}
TextView welcome = findViewById(R.id.textWelcome);
welcome.setText("Welcome, " + name);
• Extras may be absent if a screen is opened from another route.
• Provide a sensible default instead of displaying null.
• Pass only the data the destination screen needs.
• Do not place passwords or other secrets in ordinary Intent extras.

12. Common Mistakes and Best Practices
• Calling startActivity() with the wrong destination class.
• Using different extra keys when sending and receiving data.
• Forgetting to create the target Activity or its layout.
• Calling findViewById() before setContentView() for that layout.
• Assuming an extra is always present; check for null.
• Use clear key names and keep each Activity focused on one task.

13. Summary
• An Activity represents a screen in an Android app.
• An Intent requests an action or launches a component.
• Explicit Intents are useful for navigation within your app.
• putExtra() sends data; getStringExtra() retrieves a String extra.
• Implicit Intents can delegate actions such as viewing a web page.
• Validate incoming data and provide sensible defaults.
